## Intent

This is a planned project exploring what a useful local voice AI companion could feel like on consumer hardware. The focus is not on making the biggest model run; it is on understanding the end-to-end experience.

## Questions to investigate

- What makes a voice interaction feel responsive?
- Where does latency accumulate between speech input and generated audio?
- Which pieces can run locally and efficiently on CPU-first hardware?

## Status

The project has not started yet. This page will become a technical record as the architecture, benchmarks, and implementation decisions take shape.
